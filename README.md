# Robbie Wadley — portfolio

A Remix 3.0.0 portfolio using Remix's non-React component runtime. The build exports two pages, a branded `404.html`, `robots.txt`, `sitemap.xml`, and their assets to `dist/` for static hosting on Vercel; production needs no application server.

```bash
pnpm install
pnpm dev                 # http://localhost:44100
pnpm typecheck
pnpm test
pnpm exec remix doctor
pnpm build
pnpm preview             # http://localhost:5190
pnpm exec playwright install chromium  # once per machine
pnpm verify
```

`PORT` overrides the dev and preview ports. Verification starts its own preview on an available loopback port, checks the built output in headless Chromium, and stops the server afterward. Build first. Screenshots, the asset manifest, and the interaction/lifecycle report are generated under `.verify/`.

Work images include 640px and 960px WebP variants; the exporter traverses every `srcset` candidate.

`VERIFY_DIRECTORY=/absolute/path/to/export` serves a stable copy of `dist/` during verification when another agent is rebuilding the shared checkout.

The mouse cursor drives an always-solid ball through a distance-strengthened, damped spring. The ball lives in page coordinates: scrolling moves its target, so it flies across the document instead of snapping. Window exit keeps its last target and visible body. Primary clicks anywhere fire an immediate radial burst and a brief fixed-position ripple; air drag eases for the first 120ms of solver time with the original impulse and speed cap; near-center glyph taps use a consistent upward impulse so touch-coordinate rounding cannot send them sideways; links keep their native action. Switching from mouse to touch also removes the old mouse ball on hybrid devices; the next real mouse input recreates it. Touch has no ball: glyphs alone capture drags, while quick taps (under 200ms and 8px) burst. Gaps scroll normally, and the hero's lime “Explore the work ↓” anchor bypasses the letters. Reduced motion disables physics, bursts, ripples, and glyph touch capture; the anchor also works without JavaScript. Open with `?debug` to load the overlay showing actual collision parts, ball distance, hull cost, awake/asleep state, and solver steps/s; `D` toggles it on that visit. Normal visits never download or run the debug behavior.

Physics pins each glyph's rest advance and measures with rest variations; animated settings cannot change home positions. Each phase waits for its bounded collision shape before advancing; the crest then crosses rest and rebounds.

The hero collision shapes evaluate offline-baked control deltas from the bundled font, including width, weight, roundness, grade, and slant. Q64 integer coordinates reconstruct the reference outlines within 0.025 font units. A nine-factor lookup avoids scanning inactive font regions at each pose. `pnpm exec node scripts/bake-glyph-controls.mjs` regenerates the model and compresses it offline using a disposable uv environment with zopfli 0.4.3; browser decoding remains ordinary DEFLATE. Physics tunables live in `app/ui/public/physics.js`. The 60Hz simulation uses adaptive solver substeps that bound relative ball/letter travel to 6px; the integrity ceiling is 600px/frame (36,000px/s), with up to 128 substeps. Contact-aware sleep measures angular travel at each glyph body’s radius and freezes the solved pose after 30 quiet frames, including letters resting against a parked ball, and schedules no further simulation frames. The nudge skips grabbed/burst/hit/contacted glyphs, and briefly lifts a jammed rotated letter to make room to straighten.
